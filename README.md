# 九九乘法表挑战

一个纯前端、零依赖的乘法表速记训练工具，单文件 HTML 实现，打开即用。

## 功能

- **两种练习模式**
  - 输入答案：键盘直接敲数字作答，无需点屏幕；支持限时（2–15 秒可调）与不限时
  - 看答案：出题后按设定秒数（默认 3 秒）自动揭晓答案
- **限时自动判定**：时间到时取当前输入框内容判定，正确即计分，未作答按错误处理
- **错题本**：答错自动收录并累计错误次数，按次数加权；连续答对 3 次自动移出
- **错题强化模式**：在正常题组中按约 45% 比例混入错题，错得越多出现越频繁，但不会全是错题
- **统计**：正确率实时显示，跨轮次累计并本地保存，可手动重置
- **其他**：题目范围（全部 1–9 / 常用 2–9 / 单张乘法表）、乱序出题、键盘 1–9 快捷键、移动端适配

## 使用

直接用浏览器打开 `index.html`，或在项目目录起一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

设置、统计数据保存在浏览器 localStorage，仅存于本机。

## 技术说明

- 单文件，无框架、无构建步骤、无外部依赖
- 键盘事件全局监听，焦点丢失时也能继续作答
- 错题本采用「错误次数」与「连续答对次数」双计数，兼顾强化与毕业
